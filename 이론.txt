싱글톤 패턴(Singleton Pattern)

프로그램에서 해당 객체는
하나만 존재하고, 이 하나의 객체는
다른 쪽에서 언제든 접근해서
편하게 사용할 수 있습니다.

만드는 방법

public class 클래스명 
{
  public static 클래스명 Instance = null;

  private void Awake()
  {
      if(Instance == null)
      {
         Instance = this;
      }
  } 
}
1. 자기 자신의 형태의 객체를 public static으로 만듭니다.
public static으로 만들면  클래스명.Instance로  접근이
가능합니다.

프로퍼티 vs 필드?
정의 방식
public int A {get; set;} <- 프로퍼티
public int A;              <- 필드

캡슐화 여부
필드 : private 설정 해줘야 인스펙터에서 안보임.
프로퍼티 :  따로 설정 없으면 안보임.

내부 로직에 대한 제어 부분
필드 : 따로 없음. (메소드 등을 통해 조작)
프로퍼티 : get, set을 통해 제공


C# 매개변수 한정자 out
타입 앞에 붙습니다. ex) void Function(out int value);
out 한정자가 붙은 매개변수는 참조로 전달이 됩니다.
함수 내부에서 무조건 적으로 값을 설정해줘야 합니다.
